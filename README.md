# 酒桌摇骰子

### 基于vite制作的spa应用

> 可自定义1～10个骰子

## 局域网大话骰模式

现在支持由一台电脑运行游戏服务器，供同一局域网内的 2 或 3 人加入同一个房间。

```powershell
npm install
npm run dev
```

服务器启动后，在运行服务器的电脑上通过 `ipconfig` 查询 IPv4 地址。其他玩家打开：

```text
http://服务器局域网IP:3095
```

首次启动若 Windows 防火墙询问，请允许 Node.js 在专用网络通信。房主创建 2 人或 3 人房并分享四位房间码；游戏由服务器摇骰，其他玩家在开骰前无法读取你的骰子。

规则：普通叫点中 1 为万能点，叫“斋”后 1 只算 1；上家叫斋后可“飞”回普通规则，但数量须至少翻倍。轮到你时可以加叫或开骰；叫点成立则开骰者输，否则上一个叫点者输。
